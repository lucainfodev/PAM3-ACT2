1. RESUMEN DEL TRABAJO IMPLEMENTADO
--------------------------------------------------------------------------------
En esta segunda entrega se implementó la persistencia real de datos mediante
Entity Framework Core (enfoque Database First) conectado a la base de datos SQL
Server remota provista por la cátedra, junto con el sistema de autenticación y
autorización mediante JSON Web Tokens (JWT).

Componentes desarrollados:
- Modelos generados por scaffolding: Contacto, Usuario y DbA358b2Pam3Context.
- Reemplazo de ContactoService en memoria por operaciones asíncronas con EF Core
  y registro Scoped en el contenedor de dependencias.
- Controlador ContactosController con los 4 endpoints requeridos protegidos con
  el atributo [Authorize]:
    * GET  /api/contacto         -> Listar todos los contactos.
    * GET  /api/contacto/{id}    -> Obtener contacto por ID.
    * POST /api/contacto         -> Agregar nuevo contacto (201 CreatedAtAction).
    * PUT  /api/contacto/{id}    -> Editar contacto existente (200 OK / 404).
- Controlador AuthController:
    * POST /api/auth/register    -> Registro de usuarios con validación de email
                                    duplicado y contraseña hasheada.
    * POST /api/auth/login       -> Validación de credenciales y emisión de JWT.
- Documentación interactiva con Swagger UI con soporte para token Bearer.
